# エディタ機能の説明

Adbx Engine Editorの主要機能を説明します。

## ヒエラルキービュー

エンティティの階層構造を表示します。仮想スクロール機能により、大量のエンティティがある場合でも快適に操作できます。

### 操作

- **クリック**: エンティティを選択
- **右クリック**: コンテキストメニューを表示
- **ドラッグ&ドロップ**: エンティティの親子関係を変更
- **エンティティ作成/削除**: コンテキストメニューから実行

## インスペクターパネル

選択されたエンティティのコンポーネントを表示・編集します。遅延更新機能により、連続的な変更時でも応答性が維持されます。

### サポートされているコンポーネントエディタ

以下のコンポーネントに対して、専用のエディタが実装されています：

- **Transform**: 位置、回転、スケールの編集
- **Camera3d**: 3Dカメラの設定
- **Camera2d**: 2Dカメラの設定
- **Sprite**: スプライトの設定
- **Mesh3d**: 3Dメッシュの設定
- **MeshMaterial3d**: 3Dマテリアルの設定

### 操作

- **フィールド編集**: コンポーネントの値を直接編集
- **Transform入力**: 数値入力フィールドでTransform値を編集
- **コンポーネント追加**: 「Add Component」ボタンからコンポーネントを追加（将来実装予定）
- **コンポーネント削除**: 「Remove Component」ボタンからコンポーネントを削除（将来実装予定）

### 注意事項

- `InspectorPanel`リソースには遅延更新用のフィールド（`last_update_time`、`update_throttle`、`pending_update`）が定義されていますが、現在は未使用です
- コンポーネントの追加/削除機能は将来実装予定です

## アセットブラウザー

プロジェクト内のアセットを表示・管理します。仮想スクロール機能により、大量のアセットがある場合でも快適に操作できます。

### 機能

- 画像プレビューの自動更新
- ファイルシステムの監視（ホットリロード対応）

### 操作

- **クリック**: アセットを選択
- **ダブルクリック**: アセットを開く（将来実装予定）
- **右クリック**: コンテキストメニューを表示
- **インポート**: 「Import」ボタンからアセットをインポート（将来実装予定）
- **エクスポート**: 「Export」ボタンからアセットをエクスポート（将来実装予定）

## コードエディタ

コード編集機能を提供します。シンタックスハイライト、コード補完、AI統合機能をサポートしています。

### 機能

- シンタックスハイライト（syntect使用）
- コード補完機能
- AI統合（`ai` feature有効時）
- リアルタイムプレビュー

### 操作

- **Ctrl+Space**: コード補完を表示
- **マウスホイール**: スクロール
- **キーボード入力**: コード編集

## スクリプトエディタ

Luaスクリプトを編集・実行します。

### 機能

- スクリプトの構文検証
- エラー表示（行番号、列番号）
- キーボード入力処理

### 操作

- **編集**: スクリプトを直接編集
- **検証**: 自動的に構文検証が実行されます
- **実行**: 「Run」ボタンでスクリプトを実行（将来実装予定）
- **アタッチ**: 「Attach to Entity」ボタンでエンティティにスクリプトをアタッチ（将来実装予定）

### 注意事項

- `ScriptEditor`リソースには`entity`フィールドが定義されていますが、現在は未使用です
- `attach_script_to_entity`関数は定義されていますが、現在は未使用です
- `ScriptError`構造体の`column`フィールドは定義されていますが、現在は未使用です
- エンティティへのスクリプトアタッチ機能と実行機能は将来実装予定です

## ログパネル

エディタのログメッセージを表示します。

### 機能

- ログエントリの管理（`VecDeque`を使用）
- 最大ログ数の制限（`max_logs`フィールド）
- 表示/非表示の切り替え（`is_visible`フィールド）

### 注意事項

- `LogPanel`リソースには`max_logs`と`is_visible`フィールドが定義されていますが、現在は未使用です
- `add_log`メソッドは定義されていますが、現在は未使用です
- `LogLevel`列挙型（`Info`、`Warn`、`Error`、`Debug`）は定義されていますが、現在は未使用です
- `toggle_log_panel`関数は定義されていますが、現在は未使用です
- ログのフィルタリングやエクスポート機能は将来実装予定です

## ファイルダイアログ

ファイルやフォルダを選択するためのダイアログです。

### 注意事項

- `FileDialogResult`列挙型（`File`、`Folder`、`Cancelled`）は定義されていますが、現在は未使用です
- ファイル/フォルダ選択ダイアログの基盤は実装されていますが、完全なUIダイアログは将来実装予定です

## リネームダイアログ

ファイルやエンティティの名前を変更するためのダイアログです。

### 注意事項

- `RenameDialogResult`列挙型の`Renamed`バリアントには`old_path`と`new_path`フィールドが定義されていますが、現在は未使用です
- `Cancelled`バリアントは定義されていますが、現在は未使用です
- `validate_rename_name`と`generate_rename_path`関数は定義されていますが、現在は未使用です
- リネーム機能の基盤は実装されていますが、完全なUIダイアログは将来実装予定です

## リアルタイムプレビュー

コード編集のリアルタイムプレビュー機能です。

### 注意事項

- `PreviewContent`リソースには`content`と`preview_type`フィールドが定義されていますが、現在は未使用です
- リアルタイムプレビュー機能の基盤は実装されていますが、完全な機能は将来実装予定です

## シーンビュー

3D/2Dシーンの表示と操作を行うビューです。

### 注意事項

- `SceneView`リソースには`camera_entity`フィールドが定義されていますが、現在は未使用です
- シーン表示と基本的な操作は実装されていますが、一部のカメラ制御機能は将来実装予定です

## ビルド機能

ゲームをスタンドアロン実行可能ファイルとしてビルドできます。

### 操作

- **ビルド**: メニューバーから「Build」→「Build Game」を選択
- **ビルド進捗**: ビルド中は進捗ダイアログが表示されます
- **パッケージ化**: ビルド完了後、自動的にパッケージ化されます

### ビルド出力

ビルドされたゲームは`target/release/game_package/`に配置されます：
- 実行可能ファイル（`adbx_runtime.exe`または`adbx_runtime`）
- アセットディレクトリ（`assets/`）
- シーンディレクトリ（`scenes/`）
- 設定ファイル（`build_config.json`）

### ビルドシステムの注意事項

- `BuildGameMenuRequest`リソースは`app_initialization.rs`で初期化する必要があります。初期化されていない場合、起動時にパニックが発生します

## ドッキングシステム

パネルのドッキングとレイアウト管理機能です。

### 機能

- パネルのドラッグ&ドロップ
- レイアウトの保存と読み込み
- デフォルトレイアウトの使用

### 検索・置換

### エラーダイアログ

### クリップボード

クリップボード操作機能です。
