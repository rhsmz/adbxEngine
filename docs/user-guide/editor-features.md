# エディタ機能の説明

Adbx Engine Editorの主要機能を説明します。

## ヒエラルキービュー

エンティティの階層構造を表示します。仮想スクロール機能により、大量のエンティティがある場合でも快適に操作できます。

### 操作

- **クリック**: エンティティを選択
- **右クリック**: コンテキストメニューを表示
- **ドラッグ&ドロップ**: エンティティの親子関係を変更

## インスペクターパネル

選択されたエンティティのコンポーネントを表示・編集します。遅延更新機能により、連続的な変更時でも応答性が維持されます。

### 操作

- **フィールド編集**: コンポーネントの値を直接編集
- **コンポーネント追加**: 「Add Component」ボタンからコンポーネントを追加
- **コンポーネント削除**: 「Remove Component」ボタンからコンポーネントを削除

## アセットブラウザー

プロジェクト内のアセットを表示・管理します。仮想スクロール機能により、大量のアセットがある場合でも快適に操作できます。

### 操作

- **ダブルクリック**: アセットを開く
- **右クリック**: コンテキストメニューを表示
- **インポート**: 「Import」ボタンからアセットをインポート
- **エクスポート**: 「Export」ボタンからアセットをエクスポート

## コードエディタ

コード編集機能を提供します。シンタックスハイライト、コード補完、Undo/Redo機能をサポートしています。

### 操作

- **Ctrl+Space**: コード補完を表示
- **Ctrl+Z**: Undo
- **Ctrl+Y**: Redo

## スクリプトエディタ

Luaスクリプトを編集・実行します。

### 操作

- **実行**: 「Run」ボタンでスクリプトを実行
- **アタッチ**: 「Attach to Entity」ボタンでエンティティにスクリプトをアタッチ

## ビルド機能

ゲームをスタンドアロン実行可能ファイルとしてビルドできます。

### 操作

- **ビルド**: メニューバーから「Build」→「Build Game」を選択
- **ビルド進捗**: ビルド中は進捗ダイアログが表示されます
- **パッケージ化**: ビルド完了後、自動的にパッケージ化されます

### ビルド出力

ビルドされたゲームは`target/release/game_package/`に配置されます：
- 実行可能ファイル（`adbx_runtime.exe`または`adbx_runtime`）
- アセットディレクトリ（`assets/`）
- シーンディレクトリ（`scenes/`）
- 設定ファイル（`build_config.json`）
