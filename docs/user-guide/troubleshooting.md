# トラブルシューティング

よくある問題と解決方法を説明します。

## エラーが発生した場合

### エラーダイアログの確認

エラーが発生した場合、エラーダイアログが表示されます。詳細情報を確認するには、「詳細を表示」ボタンをクリックしてください。

### ログの確認

ログパネルでエラーメッセージを確認できます。また、コンソール出力でも詳細なログを確認できます。

## よくある問題

### 起動時にパニックが発生する

**エラーメッセージ例:**
```
Parameter `ResMut<'_, BuildGameMenuRequest>` failed validation: Resource does not exist
```

**解決方法:**
- このエラーは、必要なリソースが初期化されていない場合に発生します
- 最新のコードでは、`app_initialization.rs`で`BuildGameMenuRequest`リソースが初期化されていることを確認してください
- カスタムシステムを追加する場合は、必要なリソースを`app_initialization.rs`で初期化してください

### アセットディレクトリの警告

**警告メッセージ例:**
```
Skip creating file watcher because path "C:\Users\...\adbx_editor\assets" does not exist.
```

**解決方法:**
- この警告は、`adbx_editor/assets`ディレクトリが存在しない場合に表示されます
- エディタは正常に動作しますが、アセット監視機能を使用する場合は、ディレクトリを作成してください
- ディレクトリを作成するには：`mkdir adbx_editor/assets`

### シーンが読み込めない

- シーンファイルのパスが正しいか確認してください
- シーンファイルの形式が正しいか確認してください（JSON/MessagePack）
- プロジェクトが正しく開かれているか確認してください

### スクリプトが実行されない

- スクリプトの構文が正しいか確認してください
- エンティティにスクリプトがアタッチされているか確認してください
- ランタイムが正常に起動しているか確認してください

### アセットが表示されない

- アセットファイルのパスが正しいか確認してください
- アセットタイプがサポートされているか確認してください
- カスタムアセットローダーが正しく登録されているか確認してください

### ビルドが失敗する

- プロジェクトパスが正しく設定されているか確認してください
- `build_config.json`の形式が正しいか確認してください
- 必要なアセットファイルが存在するか確認してください
