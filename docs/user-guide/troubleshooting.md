# トラブルシューティング

よくある問題と解決方法を説明します。

## エラーが発生した場合

### エラーダイアログの確認

エラーが発生した場合、エラーダイアログが表示されます。詳細情報を確認するには、「詳細を表示」ボタンをクリックしてください。

### ログの確認

ログパネルでエラーメッセージを確認できます。

## よくある問題

### シーンが読み込めない

- シーンファイルのパスが正しいか確認してください
- シーンファイルの形式が正しいか確認してください（JSON/MessagePack）

### スクリプトが実行されない

- スクリプトの構文が正しいか確認してください
- エンティティにスクリプトがアタッチされているか確認してください

### アセットが表示されない

- アセットファイルのパスが正しいか確認してください
- アセットタイプがサポートされているか確認してください
